## Session 1: Why CSS? — Before vs. After

```html
<!-- BEFORE: inline HTML attributes (avoid) -->
<table border="1" bgcolor="#f0f0f0">
  <tr><td>Data</td></tr>
</table>
```

```css
/* AFTER: modern CSS (preferred) */
table {
  border: 1px solid #ccc;
  background-color: #f0f0f0;
}
```

## Session 2: Anatomy of a CSS Rule

```css
.navigation {                    /* 1. Selector: targets HTML elements   */

  padding: 20px;                 /*    (together = 5. Declaration)       */

}                                 /* 2. Declaration Block: { ... }        */
```

## Session 3: Three Ways to Write CSS

### Inline CSS
```html
<h1 style="color: #2c3e50; text-align: center;">Welcome to Our Website</h1>
<p style="color: #7f8c8d; font-size: 16px;">This demonstrates inline CSS.</p>
```
*Highest specificity, overrides everything else. Use sparingly — hard to maintain, but useful for quick JS-driven style changes or email templates.*

### Internal CSS
```html
<head>
  <style>
    body {
      font-family: 'Segoe UI', sans-serif;
      background-color: #f0f0f0;
    }
    h1 {
      color: #333;
    }
  </style>
</head>
```
*Good for single-page apps or one-off designs. Not reusable across pages.*

### External CSS (industry standard)
```html
<head>
  <link rel="stylesheet" href="static/css/reset.css">
  <link rel="stylesheet" href="static/css/main.css">
</head>
```
*Cacheable by the browser, reusable across every page, keeps HTML clean.*

## Session 5: Colors, Backgrounds & Typography

### Color formats
```css
.color-demo {
  color: #667eea;                     /* Hexadecimal */
  background-color: rgb(102, 126, 234);      /* RGB   */
  border-color: rgba(102, 126, 234, 0.8);    /* RGBA  */
  outline-color: hsl(230, 75%, 66%);         /* HSL   */
}
```

### Backgrounds & gradients
```css
.gradient-background {
  background: linear-gradient(45deg, #667eea, #764ba2);
}
```

### Typography
```css
h1 {
  font-family: 'Inter', sans-serif;
  font-size: clamp(1rem, 2.5vw, 2rem);  /* responsive font size */
  font-weight: 700;                      /* 300 light | 400 normal | 700 bold */
}
```

### Text styling
```css
h1 {
  text-align: center;
  text-decoration: underline;
  text-transform: uppercase;
  line-height: 1.6;
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
}
```

## Hands-On Lab (45 min)

**Task:** Build a single static page (profile or landing page).

1. Create the folder structure:
```
project/
├── index.html
└── static/
    └── css/
        ├── reset.css
        └── main.css
```

2. Starter `index.html`:
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Profile</title>
  <link rel="stylesheet" href="static/css/reset.css">
  <link rel="stylesheet" href="static/css/main.css">
</head>
<body>
  <header class="hero">
    <h1>Your Name</h1>
    <p class="tagline">Full-Stack Developer in Training</p>
  </header>

  <main>
    <section class="about">
      <h2>About Me</h2>
      <p>Write a short intro here.</p>
    </section>
  </main>
</body>
</html>
```

3. Starter `reset.css`:
```css
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```

4. Starter `main.css` (students fill this in during the lab):
```css
body {
  font-family: 'Inter', sans-serif;
  line-height: 1.6;
  color: #333;
}

.hero {
  background: linear-gradient(45deg, #667eea, #764ba2);
  color: white;
  text-align: center;
  padding: 60px 20px;
}

.hero h1 {
  font-size: clamp(2rem, 5vw, 3rem);
  text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
}

.tagline {
  font-size: 1.1rem;
  opacity: 0.9;
}

.about {
  max-width: 700px;
  margin: 40px auto;
  padding: 0 20px;
}
```

**Checklist:**
- [ ] External stylesheet linked (not inline/internal)
- [ ] At least 2 different color formats used
- [ ] One gradient background
- [ ] `clamp()` used for at least one responsive font size
- [ ] `reset.css` and `main.css` kept as separate files
